# Stayforlong Help Hub

Create a responsive Stayforlong Customer Care / Help Center landing page matching the attached reference image as closely as possible.

Use the reference image as the primary visual and layout reference. Recreate the same overall structure, proportions, spacing, typography hierarchy, colors, cards, icons, buttons, navigation, hero image treatment, support banner, article list, trust section, and footer.

The page should include:

- Stayforlong header/navigation

- Large travel-photo hero section

- “How can we help you?” headline with pink emphasis on “help”

- Supporting text

- Large booking/help search bar

- Four quick-help cards:

  1. Manage my booking

  2. Payment & refunds

  3. Changes & cancellations

  4. Contact support

- “What do you need help with?” section

- The six help-category rows shown in the reference:

  Booking, Hotel stay, Payments, Cancellation & refunds, Account, Travel documents

- Pink “Need help now?” support banner with Chat with us and Email us buttons

- Trending articles section

- “Still need help?” row

- Trust/support highlights

- Stayforlong footer and social icons

Use a clean white background, dark navy text, Stayforlong pink accents, subtle borders, soft shadows, rounded corners, and spacious professional layouts.

Use the exact visual design of the reference as the target. Do not redesign it into a different style.
